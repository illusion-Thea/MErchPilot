# 品策智选 MerchPilot｜简历项目经历（2026 当前版）

> 更新日期：2026 年 9 月 8 日  
> 使用建议：根据简历篇幅选择一版；不要同时堆叠所有技术名词，优先突出你能讲到代码和异常处理的核心链路。

## 一、项目标题

**MerchPilot｜企业级商品规划与智能选品 Agent 平台**

## 二、项目概述

面向零售商品运营、采购、供应链、财务和审批人员，建设从商品数据治理、证据检索、Multi-Agent 商品规划到线上审批、正式选品、商品立项、试销评估和上市评审的业务闭环。系统采用 PostgreSQL 管理业务事实，Milvus 管理证据向量，LangGraph 编排 Prompt Agent 与确定性业务工具，Celery/Redis 支撑长任务和状态恢复，React/Next.js 工作台通过 WebSocket 展示实时进度。

## 三、简历精简版（3条）

- 负责证据驱动的异步商品规划 Multi-Agent 主链路，使用 LangGraph 编排需求理解、研究规划、商品概念、方案审查和规划报告等 Prompt Agent，并衔接市场/竞品/用户检索、供应评估、财务测算和机会评分等确定性业务工具。
- 设计 PostgreSQL + Milvus 协同的企业 RAG 证据链：Milvus 负责语义召回，PostgreSQL 负责租户、质量状态、来源和审计二次校验；使用 Pydantic 约束模型结构化输出和证据引用，降低无依据结论与关键数值幻觉风险。
- 使用 Celery + Redis 实现导入、索引、规划和报告任务异步执行，补充节点级重试、指数退避、Checkpoint、幂等、分布式锁、WebSocket 进度事件和审批修订恢复；配合 React/Next.js、Docker Compose 完成本地全量闭环。

## 四、简历标准版（5条）

- 参与建设面向零售商品企划和智能选品的企业级平台，打通“数据治理—证据检索—Multi-Agent分析—线上审批—正式选品—商品立项—试销—上市评审”业务链路。
- 负责 LangGraph 规划 Mesh 核心编排，按“5个Prompt Agent + 7个确定性业务工具 + 1个人工审批门禁”拆分节点，支持市场、竞品、用户洞察并行，以及供应评估和财务测算并行。
- 建设 PostgreSQL + Milvus 的证据检索体系，完成证据质量、租户、重复治理、索引状态和来源元数据校验，结合 BGE-M3 Embedding 与 BGE Reranker 返回可追溯证据。
- 使用 Celery、Redis Checkpoint 和运行快照支持长任务异步执行、节点级重试、失败恢复、审批要求修订后的子版本运行和 WebSocket 实时进度；通过唯一约束、幂等键和分布式锁降低重复提交风险。
- 使用 Pydantic 校验请求和模型结构化输出，将毛利、盈亏平衡、供应风险、机会评分和状态流转下沉到确定性服务；参与线上审批、正式选品、商品立项、试销分析、上市评审、审计和 Docker 联调。

## 五、后端/AI岗位版

**项目描述：** 负责企业商品规划场景下的 RAG、Multi-Agent 编排和异步业务流程建设，将非结构化商品资料转化为可引用证据，并驱动商品概念、供应、财务和选品决策。

**项目职责：**

- 基于 FastAPI、SQLAlchemy、Pydantic 设计规划、检索、审批和业务闭环接口，使用 PostgreSQL 保存项目、运行、证据、审批、选品、立项、试销和审计事实。
- 基于 LangGraph StateGraph 构建共享 `MeshState` 的规划工作流，区分模型推理节点、确定性业务工具和人工审批门禁，支持并行分支、节点生命周期事件和运行快照。
- 基于 Milvus、BGE-M3 和 BGE Reranker 实现证据召回与重排，检索结果回 PostgreSQL 完成租户、质量和来源治理；模型上下文只注入有限、可追溯证据。
- 基于 Celery + Redis 完成导入、向量化、规划和报告任务队列拆分，设计节点级指数退避、Checkpoint、分布式锁、幂等键和 PostgreSQL 降级恢复。
- 使用结构化 Prompt 与 Pydantic 输出契约约束需求、商品概念、方案审查和报告结果；财务、供应、评分和状态迁移使用确定性代码，避免让 LLM 直接修改经营事实。

## 六、全栈/平台岗位版

- 参与建设 React/Next.js 企业工作台，使用 Redux Toolkit 管理项目和运行上下文，使用 Axios 封装 API，使用 Ant Design、AntV X6/Charts 和 WebSocket 完成 Agent Mesh、运行时间线、审批、分析和状态中心。
- 负责后端 FastAPI 业务接口与 PostgreSQL 事务边界，覆盖项目、运行、数据导入、检索、审批、正式选品、商品立项、试销和上市评审模块。
- 参与 Docker Compose 本地全量环境编排，包括 API、规划/索引/报告 Worker、FastMCP、PostgreSQL、Redis、Milvus、etcd、MinIO、Prometheus 和 Embedding/Reranker 服务。
- 建设权限、租户隔离、幂等、审计、分页聚合、健康检查和降级提示，确保前端断线或刷新后能够通过运行快照恢复可见状态。
